# AGENTS.md

This repository is part of the Tesseras Labs ecosystem.

## Agent baseline

- Make minimal, reversible changes.
- Avoid speculative abstractions.
- Treat compliance and money-movement code paths as sensitive surfaces.
- Document assumptions, risks, and failure modes.

## Development Assistant

Codex is the primary development assistant for planning, implementation,
verification, and review within this repository's boundaries. `AGENTS.md` is
the canonical instruction source. Claude Code is not required. Human ownership
and sensitive action-time approval gates remain unchanged.

## Organization Documentation

This repository owns organization documentation and the public GitHub profile
in `profile/README.md`. Read `CORPORATION.md` and `FOUNDER.md` for company
context and decision principles. Product and architecture authority lives in
`tesseras-architect`; workflow standards live in `dev-playbook`.

Apply safety, clarity, durable architecture, and institutional trust to edits.
Preserve issuer, investor, and execution-partner boundaries. Public compliance
claims must follow the canonical corporate wording and human approval gates.
